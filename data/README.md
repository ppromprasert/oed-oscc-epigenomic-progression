# Data

The repository does not distribute restricted patient-level research data.

The existing `data/synthetic/` directory contains demonstration inputs used to show the analytical structure.

Additional public/privacy-safe inputs expected by the expanded workflow are documented directly in the relevant scripts, including:
- exposure-signature definitions;
- all-sample beta matrices;
- privacy-safe specimen metadata;
- priority promoter methylation summaries.

Raw IDATs and restricted clinical data should remain outside the repository.
