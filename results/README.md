# Results

This directory is intended for aggregate, synthetic, public-data-derived, or otherwise approved result outputs.

Recommended public figures include:
- candidate CpG volcano plot;
- UBD CpG distribution;
- known-OSCC candidate heatmap;
- promoter methylation heatmap;
- exposure-signature heatmap;
- Ref2 exposure-score boxplots;
- exposure effect/significance plot;
- exposure-to-priority-promoter correlation heatmap;
- Mild-to-Severe trajectory plot.

The `tables/` directory contains compact aggregate summaries of the main portfolio findings.
