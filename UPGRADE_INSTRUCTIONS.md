# Upgrade Instructions

This archive is an overlay for the existing
`oed-oscc-epigenomic-progression` repository.

Recommended workflow:
1. commit the current repository;
2. create a backup branch;
3. copy this overlay into the repository root;
4. inspect `git diff --stat`;
5. run validation and privacy checks;
6. commit and push without force-pushing.

Suggested commit:

`Expand grade-adjusted modeling, CpG effect sizes, spatial integration, and lesion sensitivity analyses`
