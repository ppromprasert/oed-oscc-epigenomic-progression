# Data and Privacy

Restricted patient-level clinical, pathology, methylation, and spatial-transcriptomic data are not distributed in this repository.

Public code should operate on:

- synthetic demonstration data;
- public data;
- aggregate result tables;
- privacy-safe preprocessed inputs approved for sharing.

Do not commit institutional filesystem paths, direct identifiers, raw IDAT files, protected clinical tables, or restricted sample-level outputs.
