# Baseline Definitions

The study considered three clinically derived baseline definitions.

| Definition | Real modeled P/NP | Role |
|---|---:|---|
| Ref1 — lowest diagnosis before this lesion | 22 / 1 | descriptive |
| Ref2 — lowest-ever diagnosis for this lesion | 25 / 3 | exploratory inference |
| Ref3 — lowest diagnosis of any type before this lesion | 25 / 2 | descriptive |

Ref2 is carried forward for formal exploratory comparison because it is the only definition with at least three non-progressors after grade filtering. The imbalance remains severe and limits inference.
