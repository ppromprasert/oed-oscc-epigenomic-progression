# Known OSCC Candidates and CDKN2A

The literature-supported candidate set contained 342 retained CpGs.

No known-OSCC CpG reached FDR < 0.05 in the Ref2 grade-adjusted model.

The strongest nominal result was:

- CDH1 `cg01251360`
- logFC = -3.61
- P = 0.000737
- FDR = 0.252

CDKN2A retained 22 analyzed CpGs and showed a broad negative average methylation direction in Progressors, but no CpG passed FDR correction.

CDH1, CDKN2A, TFPI2, MGMT, ATG5, EGFR, DAPK1 and related candidates are therefore retained as biologically plausible follow-up targets rather than definitive progression markers.
