# CosMx / Spatial-Transcriptomic Integration

A spatial-transcriptomic candidate set was mapped back to the EPIC methylation data.

The candidate analysis included 355 retained CpGs.

The strongest adjusted CpG-level result was:

- UBD `cg13206902`
- logFC = 1.957
- P = 0.000132
- FDR = 0.047

This is the current candidate-focused analysis's strongest formal methylation result.

Additional genes including RNF213, MX1, IFI6, XAF1, EPSTI1 and OAS3 show nominal signals and remain exploratory.

Promoter methylation summaries are treated as a cross-platform integration layer. They do not, by themselves, establish that methylation directly regulates spatial gene expression.
