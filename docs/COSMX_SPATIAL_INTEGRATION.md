# CosMx / Spatial Transcriptomic Integration

The CosMx candidate list contains 26 genes associated with spatial transcriptomic biology. The clean project report mapped 355 retained candidate CpGs; an earlier mapping report documented 438 raw exact-gene CpGs before the clean candidate-set intersection. The public repo preserves the clean 355-CpG primary summary and documents the 193 promoter CpGs used for promoter scoring.

The gene list is enriched for interferon/inflammatory and antigen-presentation biology, including CXCL9/10/11, IFI6, STAT1, RNF213, MX1, XAF1, TAP1, GBP1/GBP5, OAS3, C1QA/C1QC, and UBD.

Two complementary analyses are performed:
1. Ref2 differential methylation in the full baseline cohort.
2. Promoter methylation z-scores in five overlapping spatial/methylation patients.

UBD cg13206902 is the only CosMx CpG reaching FDR < 0.05 in the exploratory Ref2 model.
